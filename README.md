# homebrew-tap

Homebrew formulae by juanjsebgarcia.

```sh
brew install juanjsebgarcia/tap/loudstation
```

| Formula | What it is |
|---|---|
| [`loudstation`](Formula/loudstation.rb) | LoudStation: menu bar app and CLI that detect and fix silent monitor speakers, and the video stalls they cause, on Apple Silicon Macs ([source](https://github.com/juanjsebgarcia/loudstation)) |

Formulae build from source on your Mac, so nothing unsigned is downloaded and Gatekeeper does not get in the way. You need the Xcode Command Line Tools, which Homebrew installs for you anyway.
